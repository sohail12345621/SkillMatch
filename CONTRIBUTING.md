# Contributing to SkillMatch

Thank you for considering contributing to SkillMatch!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/your-username/SkillMatch.git
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Commit your changes**:
   ```bash
   git commit -m "Add feature description"
   ```
5. **Push to your branch**:
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request**.

## Coding Guidelines

- **Backend (Java 21 / Spring Boot 3)**: Follow standard Java conventions. Ensure unit tests and compilation pass with `mvn clean compile`.
- **Frontend (React / Tailwind CSS v3)**: Use functional components with Hooks and Tailwind utility classes. Ensure zero build errors with `npm run build`.

## Reporting Issues

Report bugs or feature requests by opening an issue on GitHub.
